# مدير شبكة واي فاي تجارية (MikroTik) - نسخة C# / WPF

## البناء
ارفع المجلد إلى مستودع GitHub جديد (فرع main). يعمل Actions تلقائيًا وينتج:
- `WifiManagerSetup.exe` (مثبّت)
- `WifiManager.exe` (ملف واحد يعمل دون تثبيت ودون الحاجة إلى .NET)
حمّلهما من Actions ← آخر تشغيل ← Artifacts.

## المميزات
الباقات، توليد وطباعة الكروت، المتصلون وفصلهم، قياس الفاقد (WAN مقابل الكروت)،
فحص أمني شامل مع مطابقة الكروت بين الراوتر والبرنامج، نسخة احتياطية للراوتر،
سجل عمليات، حماية الكروت المباعة من الحذف، قفل دخول للبرنامج، وتشفير كلمة مرور الراوتر (DPAPI).

## الإعداد
1. جهّز الراوتر بـ `MIKROTIK_SETUP.rsc` (عدّل الواجهات والعناوين).
2. تبويب الاتصال: أدخل العنوان والمستخدم وكلمة المرور واسم واجهة WAN (مثل ether1).
3. بياناته في `%APPDATA%\WifiManagerCS` (منفصلة عن نسخة بايثون).
